# 規格 20261108-1 — M-Code 實拍規格(回應 M-Agent 合併實拍清單)

目的:算「誤警率 / 漏判率」(`scripts/ng-rate.mjs`),決定牛皮紙門檻 A/B(`design20261105-1.md`),並對照 ISO 15416 差異(`report20261105-3.md`,尤其 DEF 映射偏寬)。
**不改任何門檻;沒有達標的實拍數字前一律「尚未量測」。** 裝置、日期、地點由 Eric 定,本檔不排。

## 1. 數量(硬性)
| 分類 | 良品 | 不良品 | 備註 |
|---|---|---|---|
| 牛皮紙直印 ITF-14 | ≥ 30 | ≥ 30 | 誤警率分母 = 良品數、漏判率分母 = 不良品數(`src/export/ngrate.ts`),**各 ≥ 30 才出數字** |
| 貼標 ITF-14 | ≥ 30 | ≥ 30 | 同上 |
| 其他符號別(Code128 / QR / DM) | 選拍 | 選拍 | 非本輪門檻決策所需 |
合計最少 **120 張**有效標註。每張「同一實體條碼」可拍多次,但**分母以張計,不要用連拍充數**;同一條碼重拍請在備註標同一編號。

## 2. 每張要記的欄位
App 的拍照條件 log(`shotlog.ts`)已自動記:時間、版本章、裝置 userAgent / 鏡頭朝向 / 方向、請求與實拿解析度、取幀來源、快門延遲、閘門各項、px/module、傾角、等級與 pass、`humanLabel`(良/不良)。
**log 沒有、必須另記(以 shot 的 `id` 為鍵,存 CSV)**:
| 欄位 | 值 |
|---|---|
| shotId | log 的 `id` |
| 基材 | 牛皮紙直印 / 貼標 |
| 拍攝裝置型號 | 例 iPhone 14 Pro(userAgent 在 iOS 分不出機型,Eric 11-06 要求必記) |
| 人工判定依據 | 目視(Eric 裁示);記判定者 |
| 拍攝距離 cm、光源(自然光/日光燈/其他) | 自由填 |
| 實體條碼編號 | 同一條碼重拍用 |
| 不良原因 | 例:缺印、楞痕、模糊、污點(對照 DEF 映射用) |

## 3. 拍法(待 Eric 確認的推測以【推測】標示)
- 用 `https://m-code.ericchh.work/demo/mobile.html`,**先按「有新版本可用」**,確認版本章與線上 `sw.js` 前 8 碼一致,否則拍的是舊版。
- 預覽應為 1920×1080;**px/module ≥ 8** 為目標(handoff 判準)。不足時**照拍並記錄**,不要為了達標調距離而丟掉不達標的張——不達標的比例本身是資料。
- 鏡頭正對、傾角盡量 < 5°(閘門上限 5°)。【推測】另拍一小組刻意傾斜 10° 供閘門驗證,非必要。
- 光線:牛皮紙在自然光與室內光各一組【推測】,因白平衡是歷史誤判熱區(只為建議燈,不鎖快門)。
- 良/不良標準必須在拍之前由 Eric(或指定人)定義,**不可看了 M-Code 的結果再標**,否則誤警/漏判失去意義。

## 4. 多裝置
Eric 11-06 裁示可用其他裝置。**每台裝置各自累積**,不可把不同裝置混湊成一個 30 筆;若各台不足 30,結論只能寫「該裝置尚未量測」。ISO 差異對照時裝置差異併入標註。

## 5. 收件與驗算
Eric 在設定頁「複製記錄」得 JSONL → 存檔 → 與第 2 節 CSV 以 `id` 合併 → `npm run build && node scripts/ng-rate.mjs <log.jsonl>`(依基材分檔各跑一次)。
驗收判準:每類兩個分母皆 ≥ 30,指令輸出不是「尚未量測」;誤警/漏判落點見 `ngrate.ts` 預設級距(**AIAG 級距憑記憶引用、未讀原文**)。

## 6. 與其他座位的潛在衝突(不自行取捨)
| 座位 | 其需求 | 與 M-Code 的衝突 |
|---|---|---|
| M-Counter | 遠拍、倒置 | M-Code 要近拍正對、px/module ≥ 8;同一張照片不可兼得,**需分開拍** |
| M-Detector | 缺陷分級 × 10 張、3 人 × 5 張同批 | 可合併:缺陷箱面可同時當 M-Code 的「不良」樣本,但需確認缺陷是否落在條碼區 |
| M-Detector | 已知尺寸樣板 | 可共用:放入畫面即得 mm/px,對 M-Code 的尺寸量測有用,但 M-Code 實機目前 `scaleRef` 被壓成 false(A-05),**不會自動使用** |
| 全體 | 「同一支 iPhone 14 Pro」 | 與 11-06 裁示(可換裝置)不一致,清單需更新 |
