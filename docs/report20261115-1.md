# 報告 20261115-1 — 「目視正常、檢測卻 F/D」:是否過嚴?(只分析,未改任何程式與門檻)

## 結論先講
1. **黑幕**:真機連拍數張,發生一次後**自動恢復**(黑幀偵測在真機有觸發)。
2. **F/D 的主因在 DEF(元素反射不均),不是解析度、也不是 SC。** 同一個箱子的 4032 原圖(銳利、20 px/module)
   用現行方法量,DEF 在每個解析度都是 F。
3. **我們的 DEF 輸入比業界作法嚴**(有證據,見下),但**無法量化比真實檢測儀嚴多少** —— 沒有檢測儀的對照數字。
4. SC/MOD 的映射也比 ISO 嚴(`report20261105-3.md` 已記,SC 70% → M-Code 2.8 / ISO 4.0)。兩個方向的偏差同時存在,**淨效果仍未知**。

## 實測(IMG_6765.HEIC,BOX00X79,GS1-128,瀏覽器內呼叫 `demo/imgproc.js` 的現行函式)
- SC ≈ 0.70–0.72(rLight 0.75 / rDark 0.03–0.04),**不是對比不足**。
- 元素層級 ERN 分佈(4032 原圖,縮邊 3 px,374 個暗元素):**中位數 3%、P90 9%、P99 32%**。
  只有約 1% 的寬暗條內有 0.3–0.47 的亮點;放大 4 倍看是**黑條內極細的紙纖維亮點(約 3–5 px)**,肉眼不可見。
- 現行 DEF = 「所有元素、所有掃描線取最大」→ 一個亮點就讓整張 DEF 變 F。
- 現行 ERN 還有兩個與 ISO 作法不同處:**(a)** 取樣在**未經孔徑的原始單列剖面**上,且含邊界過渡像素
  (實例:暗條邊界第一個像素 = 89,條內其餘 = 2–12,光這個邊緣像素就讓 ERN = 0.37);
  **(b)** 孔徑只是 x 方向一維弦長加權(`apertureProfile`),verifier 的圓孔徑在 y 方向也平均。
- 反事實(同一影像):加 0.5X 一維孔徑 + 縮邊 0.25X,1080 寬畫面的最差線 ERN 0.48 → 0.22;
  **高解析度下幾乎不變**(0.49 → 0.47)—— 表示主因是少數亮點加單列取樣,不是單靠孔徑/縮邊就能解。

## 業界規格(來源為廠商型錄與第二手資料,**未對照 ISO 原文**,引用請再核對)
- 檢測儀:多為 **660 nm 紅光**;孔徑有 3/5/6/10/20 mil 等多檔(Axicon 6025S 列 03/05/06/10/20);
  有的預設孔徑 = **80% X 尺寸**(BV9600);Axicon 15000 依符號別與標稱條寬自動選孔徑;標示符合 ISO/IEC 15416。
- 瓦楞紙:有資料建議**用 20 mil 孔徑**,理由是「孔徑小會看到更多缺陷」。
- 掃描器(解碼端)的 PCS 下限多在 0.2–0.3(裝置各異),1D 最小解析度多見 5 mil(0.127 mm)。這是**能不能讀**的條件,不是**驗證等級**。
- GS1/PTI:牛皮紙直印 GS1-128 建議 **C(1.5)以上**;ITF-14 X < 0.635 mm 不建議直印瓦楞,3M 政策建議 ≥ 0.71 mm。牛皮紙底色本身是對比的主要障礙。

## 能與不能說的
- **能說**:目前 DEF 的量法在牛皮紙上會把肉眼不可見的纖維亮點放大成 F;業界作法(大孔徑、圓孔徑平均)會抹平它。
- **不能說**:「M-Code 整體過嚴」或「真實檢測儀會給 A/B」。沒有檢測儀對照,等級分佈未知。`spec20261113-1.md` 已寫明無驗證儀、不良品為人造。
- 解析度(px/module < 8)是**取樣條件旗標**,不是門檻過嚴;橫拿可達 ≥ 8(見 `report20261114-1.md`)。

## 建議(未動手;順序為建議)
1. **取得真值**:同一批樣品送一次真實 verifier(自有或外送檢測),哪怕只有 5–10 張。沒有真值,所有「過嚴/過鬆」都是猜。
2. **DEF 實驗**(不動門檻,只改輸入量法,旗標可關):y 方向 ±孔徑/2 平均 + 排除邊界過渡 + 以各掃描線 ERN 的高分位數代替單點最大;
   用本報告的原圖當前後對照,再用實拍資料驗誤警/漏判。
3. 之後才議 SC/MOD 映射(`report20261105-3.md` §4)。
4. 檢視是否改用**紅色通道**(對齊 660 nm)取代亮度灰階 —— 牛皮紙與藍黑油墨的對比在紅光下可能不同(未驗)。
