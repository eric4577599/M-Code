1. 系統概觀與兩個入口

本系統針對瓦楞紙箱上的一維條碼(ITF-14、GS1-128)與二維碼(QR、DataMatrix)做現場品質快篩: 先以「六項品質燈號」把關拍攝條件,再解碼、換算相對參考等級(A–F),依驗收政策(ITF-14 ≥ C、GS1-128 ≥ B;QR / DataMatrix 目前採預設門檻 ≥ C)判定通過與否。

入口網址用途
手機版 https://m-code.ericchh.work/demo/mobile.html 用手機相機真實拍攝、真實解碼(ZXing)、真實影像量測的現場檢驗頁。無相機時可用「示範情境」模擬。
桌面展示版 https://m-code.ericchh.work/demo/index.html 對客戶簡報 / 內部驗證用的完整功能展示:情境模擬、掉級診斷、尺寸量測、CSV、ERP 回寫(模擬)、趨勢圖。
也可在本機直接以 HTTP 伺服器開啟 repo 內 demo/mobile.html、demo/index.html。 注意:手機相機需要 HTTPS(或 localhost),用 file:// 或純 HTTP 的區網 IP 開啟時相機不會啟動,只能走示範情境。

2. 手機版操作流程(真實掃描)

1
開啟頁面並允許相機
進入頁面會自動要求相機權限(優先使用後鏡頭)。授權成功後觀景窗會顯示即時畫面, 相機狀態列顯示「● 相機已開啟 · 對準條碼後按快門檢驗」。若被拒絕,依畫面提示到 iPhone 設定 → Safari → 相機允許後,點畫面任意處重試。
2
選擇檢驗條件
上方依序選:製程環節(產線 / 出貨 / 客訴)、符號別(ITF-14 / GS1-128 / QR / DM)、 工法 / 楞型基準檔(下拉選單)。此選項依箱面印刷方式選擇(直印 C 楞 / 直印 E 楞 / 表貼 / 標籤面材);手機版此選項記錄於報告欄位,不影響分級。實拍解碼成功時,符號別會依實際解出的格式自動切換,驗收門檻亦隨之切換(例:解出 GS1-128 即改用 ≥ B)。
3
對準條碼,等六燈號放行
建議距條碼約 15–20 公分、讓條碼佔滿觀景窗。相機開啟後每 0.5 秒對畫面做一次即時量測(對焦、眩光、白平衡、楞痕為實測值), 六燈號與右上角狀態標籤即時更新。狀態為 ARMED 時快門變綠色可按; 有 FAIL 燈時為 LOCKED 快門鎖死(比例尺卡除外,見第 3 章)。
4
按快門檢驗
按下綠色快門後,系統對這一張照片做單次 ZXing 解碼與影像量測(光度參數 SC / MOD / Rmin 實算), 換算相對等級與判定,自動切到結果頁,並將該筆(含實拍縮圖)存入清單。
5
繼續下一張或輸出報告
結果頁按「↻ 再拍一張」回拍攝頁;右上角「清單 N」進入清單 / 輸出頁(見第 5 章)。

無相機時:示範情境

拍攝頁底部展開「示範情境(無相機時用)」,提供 7 個預設情境一鍵套用: 理想、楞痕偏高、低對比、套印不準(2D)、失焦、眩光、不可讀。 點選後燈號與模擬參數立即切換;除「失焦」「眩光」(示範快門鎖死)外,可照常按快門走完整流程(此時為模擬值,非實拍)。

相機已開啟時,燈號一律以即時實測為準(對焦、眩光、白平衡、楞痕每 0.5 秒實測會覆蓋示範值),示範情境僅在無相機時完整生效;「比例尺卡」亦維持未偵測,避免展示文字與實際狀態不符。

3. 六項品質燈號與快門狀態機

燈號檢查內容來源(手機版實拍時)
對焦影像清晰度(Laplacian 變異數)即時實測
眩光過曝反光面積比例即時實測
楞痕透印瓦楞楞痕造成的週期性明暗即時實測
白平衡色偏程度(灰界近似)即時實測
比例尺卡尺寸換算基準卡是否入鏡實機尚未支援偵測,固定顯示「未偵測」
印向直立條碼印向 / 透視角度解碼成功後由定位點回填

燈號三色:OK(綠)通過; WARN(黃)仍可拍,拍攝頁會提示數值可能受影響(例如受楞痕影響); FAIL(紅)快門鎖死。

狀態意義快門
SCANNING尚未偵測到條碼時的狀態;本 demo 載入後即完成偵測,實際操作上不會看到此狀態灰色,不可按
ARMED全綠 / 黃,拍攝條件放行綠色,可按
LOCKED有 FAIL 燈鎖死
比例尺卡是唯一例外:未偵測到時只停用尺寸量測(X 寬 / BWR / Quiet Zone), 不鎖快門、不影響拍攝與分級。所以「五綠一紅(比例尺卡)」仍然可拍。 設計目的:強制每次拍攝條件一致 —— 穩定優先於單張精準。

4. 結果頁判讀

區塊內容
解碼狀態✓ 解碼成功(含解出字串;2D 維度僅示範情境顯示)或 ✗ 不可讀(綜合崩壞)
參考等級圓環A–F 相對等級,顏色隨等級變化;下方紅字為「非 ISO 合規證書」聲明
判定通過 / 未通過,附驗收門檻(ITF-14 ≥ C、GS1-128 ≥ B;QR / DataMatrix 目前採預設門檻 ≥ C)與 margin(離門檻的餘裕分數)
辨識文字解碼出的原始字串,可長按複製
參數列光度參數(SC / MOD / Rmin)顯示等級(分數見「判定後內容」摘要)免費版;幾何參數(DEC / DEF / FPD / GNU)以 🔒 代號鎖定 付費版
判定後內容整份文字摘要(製程、符號別、解碼、等級、判定、參數),可全選複製貼到聊天 / 郵件
margin 怎麼看:margin 為總分減門檻分。正值 = 高於門檻(越大越安全);接近 0 = 貼著門檻跑,建議關注製程;負值 = 未通過。

5. 清單與報告輸出(PDF / Excel)

每按一次快門檢驗,結果即自動存入清單(手機版含實拍縮圖;示範情境掃描為示意圖)。點右上角「清單 N」進入:

1
填寫表頭:客戶名稱、品名、工單號(掃描總數自動帶入)。
2
檢視清單:每筆含縮圖、時間、製程環節、符號別、解碼字串、等級、判定。點縮圖可放大檢視(燈箱),點任意處關閉。
3
🖨 輸出 PDF:叫出系統列印對話方塊,選「另存為 PDF」。首頁為表頭 + 判定總表,次頁起每筆掃描一頁(原圖 + 等級 + 判定 + 參數明細)。
4
⬇ 輸出 Excel:直接下載 檢驗報告_<工單號>.xls,含表頭與逐筆明細(等級、判定、門檻、margin、工法 / 楞型),表尾同樣附有護欄聲明(相對代理值、非 ISO 合規驗證、不出具證書)。
5
清除清單:清空所有累積紀錄(不可復原)。按下立即清空,無確認對話方塊,請先確認已輸出報告。
清單留存與 PDF / Excel 報告屬付費版功能(免費版單機不留存);Demo 頁面開放試用展示,重新整理頁面後清單即消失。

6. 桌面展示版操作(展示 / 工程模式)

桌面版 demo/index.html 為全模擬展示(無相機),頂部四個分頁 + 右上「展示 / 工程」模式切換。

① 拍攝

以 chip 選製程環節、工法 / 楞型、符號別;右側燈號較手機版六項多出「透視」「解析度」,共 8 項檢查。 展示模式提供 8 個情境按鈕(理想樣本、楞痕偏高、墨量過多、牛皮吃光、套印不準、失焦、眩光過強、不可讀), 每個情境標明會觸發的診斷規則;工程模式改為滑桿:閘門參數(varLap、眩光%、楞痕 ampRatio…)即時反映燈號與快門;分級 proxy 參數(R_light、R_dark、邊緣對比、DEC、DEF、BWR…)調整後需再按「檢驗」,於結果頁觀察等級變化。

② 結果

比手機版多出三塊:

區塊內容
尺寸量測X-dimension、條寬增益 BWR、Quiet Zone、楞痕週期,附規格判定(正常 / 偏高);2D 符號時改顯示模組尺寸與解碼維度
印刷掉級診斷命中之診斷規則(如 WASHBOARD、BWR_GAIN、LOW_CONTRAST、QR_REGISTRATION、NO_DECODE),每條附成因與處方
動作⚑ 標記製程;⬇ 存成 CSV(22 欄固定格式)付費版(Demo 開放試用);⇪ 回寫 ERP(模擬)付費版:展示 GET 工單門檻 → POST + Idempotency-Key → 201 → SYNCED 的完整交握
桌面展示版為付費功能的完整展示:分級參數含幾何參數(DEC / DEF / FPD / GNU 等),等級與分數完整展開、不做 🔒 鎖定;解碼列另顯示與預期資料的比對結果(符合 / 不符)。

工程模式額外顯示「工程明細」:完整 pipeline 物件 JSON(grade / measurement / acceptance / diagnosis)。

③ 清單 / 輸出

操作同手機版第 5 章(表頭 → 清單 → PDF / Excel / 清除)。桌面版清單縮圖為示意圖(非實拍);PDF / Excel 明細另多含「診斷」欄。

④ 趨勢 付費版 · 需後台

近 10 批參考等級走勢:紅虛線為門檻,趨近門檻的批次以紅圈預警;統計卡顯示平均等級、趨近門檻比例、近 3 批走勢箭頭。 切換楞型基準檔可展示「楞越粗越易掉級」:粗楞貼門檻跑、細楞 / 表貼抬高、標籤穩在 A 帶邊緣。初始走勢為預載示意資料,之後每按一次快門累積一批。

8. 常見問題排除

症狀原因與處理
相機打不開,顯示「需 HTTPS 才能開相機」用 HTTP / file:// 開啟。改走 https://m-code.ericchh.work/demo/mobile.html 或 localhost。
顯示「相機權限被拒」iPhone:設定 → Safari → 相機 → 允許;或點網址列 AA → 網站設定。Android Chrome:網址列鎖頭 → 權限 → 相機 → 允許。設好後點頁面任意處重試。
顯示「相機被其他 App 佔用」關閉相機 App 或其他使用相機的分頁後,點畫面重試。
快門一直鎖死(LOCKED)看哪顆燈是紅的:失焦 → 靠近 / 遠離讓畫面清晰;眩光 → 避開反光、換角度;楞痕 → 換光源方向;白平衡 → 避開有色光源、改白光環境。比例尺卡紅燈不會鎖快門。
拍了但顯示「不可讀」照片上無法解出條碼:對準置中、放大占框、保持直立後重拍。系統仍會給出該照片的光度分級供參考。
尺寸量測沒有數值比例尺卡未偵測時尺寸量測停用(實機目前固定未偵測),屬預期行為;不影響分級與判定。
輸出 PDF 沒反應清單為空時輸出按鈕停用;先完成至少一筆檢驗。彈出的是系統列印視窗,請確認瀏覽器未封鎖。
開啟 Excel 檔跳出「檔案格式與副檔名不符」警告屬預期行為:報告以網頁表格格式封裝為 .xls,按「是」開啟即可,內容不受影響。
重新整理後清單不見預期行為:免費版單機不留存,Demo 清單只存在當前頁面工作階段。
本手冊可直接以瀏覽器列印/另存 PDF(目錄後自動分頁);列印時請勾選「背景圖形」。
